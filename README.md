# Workforce Hub - Attendance & Absence Management System

Workforce Hub is a web-based application designed to streamline employee attendance tracking, leave requests, and administrative reporting. 

## 🚀 Features

* **Admin Dashboard:** Manage system settings, view overall company attendance, and oversee employee data.
* **Employee Portal:** View attendance history, check remaining leave balance, and submit absence requests.
* **Manager Review:** Review, approve, or reject employee leave and attendance adjustment requests.
* **Attendance Logs & History:** Track real-time sign-ins, sign-outs, and historical attendance records.

## 🛠️ Tech Stack

* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite / Relational Database
